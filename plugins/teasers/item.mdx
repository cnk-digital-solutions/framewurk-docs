**Teaser Item** is a child of the [Teasers](/plugins/teasers) widget. Each item is one card: an image at the top, an optional topic label, and a heading that acts as the card's link.

## Pre-filling from an FT.com article

Paste an **FT.com article URL** and leave the field: the heading, topic, image and an external link to the article are filled in automatically. Everything can then be edited - the URL is only used for the fetch, so changing the fields afterwards does not undo your edits.

If the fetch fails (for example for a very fresh or non-public article), fill the fields in by hand.

## The image

Two sources are possible, and the uploaded image wins:

- **Raster image** — an image from the media library. It is cropped to landscape (273 × 153) using the subject location set on the file, so any reasonably sized landscape image works.
- **Image URL** — filled by the automatic fetch; used only when no raster image is selected.

A card with neither simply has no image.

## The link

The **heading** is the clickable element of the card. Choose an **Action** as on other plugins; articles fetched from FT.com get an external link opening in a new window.
