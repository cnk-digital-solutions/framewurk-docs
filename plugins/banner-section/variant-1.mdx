**Banner (Variant 1)** is a child of a [Banner Row](/plugins/banner-section/row). It shows an image, a heading, optional text and a CTA on a background colour: the standard product promotion, for example a packshot next to "Explore our full range of subscriptions".

Use it when the message is text next to a graphic. When the message is the graphic itself, use [Banner (Variant 2)](/plugins/banner-section/variant-2).

## What it shows

- **Image**: a JPG, PNG or SVG. The banner sizes it for you, see [how the image is sized](#how-the-image-is-sized).
- **Heading** and an optional **Text** line. Both accept the usual text tags for line breaks and non-breaking spaces.
- The **CTA**: its label and an **Action**, which can be a campaign page, an external destination, an email or phone trigger, an overlay, an anchor on the page, or a scroll to one of the tabs of the first Products section.
- **Background colour**, per breakpoint, from the fixed palette (black, slate, white, paper, pink, and white 40% on paper). The XL colour is the default for the smaller breakpoints; tick a breakpoint to override it. There is no background image on this variant.
- **Vertical alignment**, per breakpoint like the background colour: where the content sits when a taller banner in the same row stretches this one, see [the tallest banner wins](/plugins/banner-section/row#height-the-tallest-banner-wins).

The image has no alt text of its own on this variant: the heading beside it carries the message. To give the image an alt text, set the **default alt text** on the file in the media library.

## Layout per breakpoint

| Breakpoint | Layout |
| --- | --- |
| Below 740px (S and XS) | A card: the image centred on the background colour in the top part, below it a bordered white body with the heading, text and the CTA as a **text link** |
| M (740 to 1023px) | The background colour fills the banner. One banner in the row: image on the left, content on the right. Two in the row: image above the content. Three in the row: one per row, image on the left as in a single banner, the heading at its three-per-row size. A single banner in a section that also holds a row of three takes that heading size at M too |
| L and XL (1024px and up) | One or two banners in the row: image on the left, content on the right. Three in the row: image above the content |

From M up the CTA is an outlined button; below it is a text link. The heading is larger when the banner has the row to itself, except at M in a section that also holds a row of three (see above).

## How the image is sized

The banner never shows the file you upload at its own size. The **width is fixed per layout and breakpoint**, and the height follows the proportions of your file.

| Banners in the row | Below 740px (S and XS) | M (740 to 1023px) | L and XL (1024px and up) |
| --- | --- | --- | --- |
| One | 200px | 260px | 260px |
| Two | 200px | 270px | 270px |
| Three | 200px | 260px (one per row there) | 250px |

What this means for your file:

- **The height is free.** A 600 x 378px upload becomes 260 x 164px in a single banner and 200 x 126px on a phone. Nothing is cropped.
- **The image is never enlarged.** If your file is narrower than the width in the table, it is shown at its own size and the retina copy is smaller than intended. Upload at least **twice the largest width the image will be shown at**: 540px wide covers every layout.
- In the side-by-side layout the image takes at most about half of the banner's width, so the text keeps its room. At the narrow end of L this makes the image narrower than the table says: with two banners in a row from 1024 to 1367px, with three from 1024 to 1085px.

Use a **PNG with a transparent background** when the graphic should sit directly on the background colour, as the packshots in the designs do. A JPG shows its own rectangle.

### Overriding the width per breakpoint

To show the image narrower than the table says, set an **Image max-width** in pixels on the breakpoint: 120 at XL shows it 120px wide on XL screens, centred in the card below 740px and keeping its place beside the content above. The setting is the one per-breakpoint setting that does **not** inherit: each breakpoint uses only its own value, and a breakpoint without one (or not ticked) keeps the width from the table. A value above the table's width changes nothing, the image is never enlarged.

## Troubleshooting

| Symptom | Likely cause |
| --- | --- |
| The image looks soft on a retina screen | The file is narrower than twice the width in the table, so the retina copy could not be made at full size. Upload a larger file. |
| The image is smaller than the width in the table | The file itself is narrower than that width. Images are never enlarged. |
| The image is a different width on a tablet than on desktop | By design: the widths differ per breakpoint and per number of banners in the row, see the table. |
| The image has no alt text | Set the **default alt text** on the file in the media library. The heading is not used for it on this variant. |
