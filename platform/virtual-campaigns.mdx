A **Virtual Campaign** is a campaign URL that serves content from one or more other campaigns based on targeting rules. The user's URL does not change—only the rendered content does.

## Create a virtual campaign

<Steps>
  <Step title="Open the Virtual Campaign">
    Create a new Virtual Campaign or open an existing one.
  </Step>
  <Step title="Set the fallback content pointer">
    Set the **fallback content pointer**. This is the content shown when no more specific targeting rule applies.
  </Step>
  <Step title="Add content pointers">
    Add a content pointer for each targeted content source.
  </Step>
  <Step title="Configure country or region targeting">
    For each content pointer, configure optional country or region targeting.
  </Step>
  <Step title="Configure date and time targeting">
    Configure optional date and time targeting on each content pointer.
  </Step>
  <Step title="Order by priority">
    Drag content pointers to arrange priority. More specific rules should sit above broader rules so they take precedence.
  </Step>
  <Step title="Save and test">
    Save the Virtual Campaign and test its URL.
  </Step>
</Steps>

## Example: temporary weekend content

This example swaps the `/products` and `/viewsubscriptions` campaigns to weekend-only content without changing the URLs users visit.

<Steps>
  <Step title="Rename the source campaign slugs">
    1. Change the original `/products` campaign slug to a content slug such as `/products-content`.
    2. Change the original `/viewsubscriptions` campaign slug to a content slug such as `/viewsubscriptions-content`.
  </Step>
  <Step title="Create the virtual campaigns">
    1. Create a new virtual campaign with the slug `products` and set fallback content to `/products-content`.
    2. Create a new virtual campaign with the slug `viewsubscriptions` and set fallback content to `/viewsubscriptions-content`.
  </Step>
  <Step title="Add the weekend content pointers">
    In both virtual campaigns, add content pointers to `/weekendexp` active from **6 am Saturday to 6 am Monday** for each target weekend.
  </Step>
  <Step title="Clean up after the campaign">
    When the campaign ends, either leave expired pointers in place for reuse, or delete them and keep only the fallback pointer.
  </Step>
</Steps>

<Note>
  To edit content, go to the **source campaign slug** (for example, `/products-content`) rather than the virtual campaign URL.
</Note>
